# The Inner Atlas

A responsive, interactive introduction to ten principal Upanishads. The experience combines a concept constellation, text profiles, shared Śānti mantra groupings, comparison tools, concept paths, and client-side search.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Validate

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Content status

The summaries, passage excerpts, mantra meanings, and transliterations are working editorial content for a prototype. Recitational traditions vary, and all Sanskrit, translations, citations, rights, and interpretations should receive qualified editorial review before scholarly or public-authority use.

See `PLAN.md` for the full product and implementation rationale.
